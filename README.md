# PAPEI SC v2 (βήμα 2: οπτικός επεξεργαστής)

## Τι περιέχει
- `index.html`, `css/`, `js/`, `data/data.js`, `assets/`: το site, χωρισμένο σε αρχεία (χωρίς base64).
- Επίσημο λογότυπο ως favicon (`favicon.ico`, `assets/favicon-32.png`, `apple-touch-icon.png`, `manifest.webmanifest`). Το πρωτότυπο είναι στο `assets/logo-original.png`. Έγινε μόνο αλλαγή μεγέθους.
- Φωτεινό θέμα ως προεπιλογή, κουμπί ήλιου/φεγγαριού, αποθήκευση επιλογής, μενού κινητού, σωστή ώρα Ελλάδας στην αντίστροφη μέτρηση, λήξη του «επόμενου αγώνα» 2 ώρες μετά την έναρξη, συνολικά στατιστικά που υπολογίζονται από τα δεδομένα.
- `supabase/schema.sql`: βάση δεδομένων με κανόνες ασφαλείας (RLS), αποθήκευση εικόνων και προστασία από διπλά γκολ.

## Ανέβασμα στο GitHub
1. Στο repo `papeisc/papeisc`, διέγραψε το παλιό `index.html` και ανέβασε όλο το περιεχόμενο αυτού του φακέλου (Add file > Upload files).
2. Settings > Pages: branch `main`, φάκελος `/ (root)`.

## Supabase: βήματα (μία φορά)
1. SQL Editor: τρέξε πρώτα `supabase/schema.sql` και μετά `supabase/migration_002.sql`.
2. Authentication > Users > Add user: φτιάξε τον λογαριασμό σου (email και κωδικός). Αυτός είναι ο μοναδικός διαχειριστής.
3. SQL Editor: `insert into admins select id from auth.users where email = 'ΤΟ_EMAIL_ΣΟΥ';`
4. Άνοιξε `https://papeisc.github.io/papeisc/admin/`, συνδέσου, πήγαινε στο «Εργαλεία» και πάτησε «Εισαγωγή» (περνά τα τωρινά δεδομένα του site στη βάση).
5. Από εκεί και πέρα όλα γίνονται από το admin: παίκτες και φωτογραφίες, αγώνες (και ο επόμενος), γκολ/ασίστ/παρουσίες ανά αγώνα, logos ομάδων.

Αν το Supabase δεν απαντά, το site δείχνει τα τοπικά δεδομένα του `data/data.js`.
Τα σύνολα παικτών που υπάρχουν σήμερα μπαίνουν ως «βάση». Καταχώρησε γεγονότα (γκολ/ασίστ) μόνο για νέους αγώνες, ώστε να μη διπλομετρηθεί τίποτα.
Το δημόσιο κλειδί στο `js/config.js` είναι ασφαλές να φαίνεται. Ο κωδικός της βάσης ή το service_role κλειδί δεν μπαίνουν ποτέ στο repo.

## Οπτικός επεξεργαστής (admin > Εμφάνιση)
- Χρώματα (ομάδας, συνδέσμων, φόντου, κειμένου) χωριστά για φωτεινό και σκούρο θέμα, γραμματοσειρά (Geom, Inter, Poppins, Montserrat, συσκευής, Georgia) και σειρά/εμφάνιση των ενοτήτων. Η σειρά ισχύει και για το μενού.
- Ζωντανή προεπισκόπηση του πραγματικού site μέσα στη σελίδα (με κουμπί Κινητό/Υπολογιστής).
- **Αποθήκευση πρόχειρου**: κρατά τις αλλαγές στη βάση χωρίς να φαίνονται στο site. **Δημοσίευση**: τις στέλνει στο site. **Απόρριψη πρόχειρου** γυρίζει στα δημοσιευμένα. **Προεπιλογές** φέρνει τις αρχικές ρυθμίσεις.
- Δεν χρειάζεται νέο SQL: χρησιμοποιεί τον πίνακα `site_settings` (στήλες `draft` και `published`) που υπάρχει ήδη. Ανέβασε το `js/design.js`, το `index.html` και το `admin/index.html`.
- Το πρόχειρο είναι αναγνώσιμο από το δημόσιο API (το λέει και το schema). Μη γράφεις εκεί τίποτα εμπιστευτικό.

## Τι λείπει ακόμα
Αυτόματη εισαγωγή από το Προπάθλημα (αγώνες, βαθμολογία) και το SofaScore. Έρχεται ως επόμενο βήμα.
